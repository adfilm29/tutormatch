# TutorMatch — Student & Teacher Learning Community

TutorMatch is a browser-first learning platform prototype with two connected experiences:

1. **Find a teacher:** discover sample educator profiles by subject and teaching style, then send an academic study request.
2. **Student Commons:** publish discussions, share ideas, respond to classmates and mark useful posts.

## Run locally

- Open `index.html` in a modern browser, or use VS Code Live Server.
- No build tools or package installation are required.

## Current prototype features

- Teacher search and filters for subject and teaching style.
- Study request form.
- Student discussion feed with topic categories.
- Create discussions, add replies and mark posts helpful.
- Responsive layout for desktop and mobile.
- Browser `localStorage` persistence.

## Important limitations

This is a front-end prototype. Educator profiles are fictional examples. Study requests and community posts are stored only in the current browser and are **not shared between users**. There is no server, authentication, real teacher verification, live messaging, moderation dashboard, or cross-device synchronization yet.

Before a real campus launch, add a secure backend and database, verified student/teacher accounts, role-based permissions, reporting and moderation, privacy controls, and institution-approved safeguarding procedures. Do not enter sensitive personal information in this demo.

## Suggested next development milestones

1. Backend API and database (e.g. PostgreSQL).
2. Verified student and teacher sign-in.
3. Real study request notifications and availability scheduling.
4. Shared discussion feed, moderation tools and reporting.
5. Deployment, tests, accessibility and security review.
